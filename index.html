Final Year Project

Petrol Price Prediction via USD Exchange Rates

View Repository
2025 - 2026

Introduction

A predictive modeling project focused on forecasting future petrol prices by analyzing historical relationships between petroleum market trends, USD/PKR exchange rates, and other economic factors.

Problem Statement

Fluctuations in exchange rates and petroleum-related economic factors can affect domestic petrol prices, creating uncertainty for businesses and consumers.

Objectives

  • Develop a machine learning/deep learning model to forecast petrol prices.
  • Analyze historical trends and relationships between economic variables.
  • Visualize historical and predicted petrol prices through data analytics dashboards.

Technologies Used

Python TensorFlow Pandas Scikit-Learn SQL Power BI

Methodology

Developed a time-series forecasting system using LSTM (Long Short-Term Memory) to analyze historical petrol price data and relevant economic indicators including Brent crude oil prices, USD/PKR exchange rate, and petroleum levy.

Key Features

  • Data preprocessing and cleaning
  • MinMaxScaler normalization
  • LSTM-based time-series forecasting
  • Dropout layers to reduce overfitting
  • Model evaluation using MAE and RMSE
  • Power BI visualization/dashboard

Results

The model was evaluated using standard regression metrics including MAE and RMSE and was used to generate forecasts of future petrol prices.
